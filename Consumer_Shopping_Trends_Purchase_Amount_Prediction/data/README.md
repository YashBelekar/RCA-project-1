# Dataset

Run `python download_dataset.py` from the project root to download the public CSV into this folder.

Source: https://raw.githubusercontent.com/SahilYadav-op/Consumer-shopping-trends-analysis/main/Consumer_Shopping_Trends_2026%20%286%29.csv

The dataset is not fabricated or silently replaced with synthetic records. If the source is unavailable, the downloader stops with an actionable error.
